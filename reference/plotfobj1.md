# plotfobj1

plotfobj1

## Usage

``` r
plotfobj1(fobj, additems = TRUE, addfoot = TRUE, addhead = TRUE)
```

## Arguments

- fobj:

  a forest plot object or a list of fobj with the same layout length

- additems:

  logical, whether items are plotted

- addfoot:

  logical, whether a footer is added

- addhead:

  logical, whether a header is added

## Value

a plot
